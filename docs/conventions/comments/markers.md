# 标记（TODO / FIX / HACK / NOTE）

适用范围：需要给未来留一句可搜索的便签时。全仓只用以下四种，跨端统一。

## 规则

- MUST 四种标记全大写 + 冒号 + 一个空格，独立成行、紧贴相关代码：`TODO(#号):`、`FIX(#号):`、`HACK(#号):`、`NOTE:`。理由：统一、可被 grep / 工具识别、好看。
- MUST TODO / FIX / HACK 带工单号（如 `TODO(#12):`），且工单真实存在。理由：可追踪，避免 orphan。
- MUST 标记后是具体动作 / 具体事实。理由：`TODO:` 空标记没有信息量。
- MUST NOTE 写「容易误解但不是缺陷」的关键背景（如 `NOTE: 金额单位是分`），无需工单。理由：只传背景、不制造任务。
- MUST HACK 写清绕行方案，并带工单号与去除条件。理由：技术债可见、可清理。
- MUST NOT 自造别名（`FIXME` / `XXX` / `WARN` / `QUESTION` / `PERF` 等）。理由：统一，否则工具抓不全、也不好看。
- MUST NOT 用 TODO 掩盖当前任务未完成。理由：该做的当场做完。

## Checklist

- [ ] 仅四种标记，格式 `大写: ` 统一
- [ ] TODO/FIX/HACK 带真实工单号，内容具体
- [ ] NOTE 是背景非缺陷，HACK 有去除条件
- [ ] 无自造别名，无空标记
