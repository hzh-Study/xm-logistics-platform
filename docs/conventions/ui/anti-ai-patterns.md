# 反「AI 味」清单

适用范围：所有界面。本文件是禁止清单与正向目标；通用视觉规范见 `design-system.md`。

## MUST NOT（出现即视为不合格）

- 紫 / 蓝紫渐变、渐变按钮、渐变背景。理由：最典型的 AI 生成痕迹。
- emoji 当图标。理由：渲染不一致、显廉价。
- 「三卡并排 + 大圆角 + 大阴影」的通用模板布局。理由：与业务无关，像占位模板。
- 装饰性 blob、网格背景、漂浮动画。理由：业务后台不需要装饰。
- 「欢迎使用 XX 平台」类空话标题。理由：无信息量。
- Lorem / `示例数据` / `TODO` 当真实内容展示。理由：交付物不应含占位。
- 每种状态配不同颜色造成花哨。理由：语义色只表达状态。

## 正向目标（做到）

- 贴近真实业务后台的信息密度：表格、筛选、状态标签。理由：用户要的是能干活的系统。
- 真实业务文案的空状态 / 错误状态（如「暂无待承接的运输订单」）。理由：空态也要传达信息。
- 单一强调色 + 克制圆角阴影 + 排版层级。理由：专业克制。
- 司机 H5：拇指可达的触控区、移动表格转卡片（见 `layout-responsive.md`）。理由：移动场景。

## Checklist

- [ ] 无渐变 / emoji 图标 / 模板三卡 / 装饰背景 / 空话标题 / 占位内容
- [ ] 信息密度贴近真实业务后台
- [ ] 空态与错误态是真实业务文案
- [ ] 单一强调色、排版层级、克制装饰
