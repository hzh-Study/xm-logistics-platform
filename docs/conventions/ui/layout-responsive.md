# 布局与响应式

适用范围：页面骨架、栅格、Web 三端与司机 H5 适配。

## 规则

- MUST Web 三端共用一套布局壳（侧边导航 + 内容区），按角色显示不同菜单项。理由：同一入口、体验一致。
- MUST 司机 H5 为单列、拇指可达布局，底部导航固定。理由：单手移动操作。
- MUST 表格在窄屏转为卡片列表，MUST NOT 让用户在手机上横向滚动宽表。理由：移动端可读性。
- MUST 触控目标不小于约 44×44px，相邻可点元素留间距。理由：防误触（见 `accessibility.md`）。
- MUST H5 适配安全区（`env(safe-area-inset-*)`），关键操作不被刘海 / 底栏遮挡。理由：全面屏兼容。
- MUST 间距只用 design token 的刻度（如 4/8/12/16/24），MUST NOT 随意写像素。理由：间距统一。
- MUST 内容区最大宽度受限，长文本可读，MUST NOT 拉伸到超宽屏。理由：阅读舒适度。

## Checklist

- [ ] Web 共用布局壳，按角色显示菜单
- [ ] H5 单列 + 底部导航 + 表格转卡片
- [ ] 触控区 ≥44px，安全区适配，间距走 token
