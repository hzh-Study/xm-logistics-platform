# 可访问性

适用范围：所有交互元素。目标：键盘可用、屏幕可读、移动可点。

## 规则

- MUST 所有可交互元素可用键盘到达，焦点样式清晰可见。理由：键盘与读屏用户可用。
- MUST 表单 label 与控件关联（`<label for>` 或包裹），图标按钮有 `aria-label`。理由：读屏能读出用途。
- MUST NOT 仅靠颜色表达状态，须同时有文字 / 图标区分。理由：色觉障碍用户可辨。
- MUST 正文与背景对比度达标（约 4.5:1），禁用低对比浅灰。理由：可读性。
- MUST 触控目标 ≥44×44px，相邻元素留间距。理由：防误触（见 `layout-responsive.md`）。
- MUST H5 在微信内打开可正常缩放，MUST NOT 禁用 viewport 缩放。理由：视力辅助。
- MUST 弹层可聚焦、可 Esc 关闭、焦点回归触发元素。理由：键盘操作闭环。

## Checklist

- [ ] 键盘可达、焦点可见、Esc 关闭弹层
- [ ] label / aria-label 齐全
- [ ] 状态不靠纯颜色，对比度达标
- [ ] 触控区达标，未禁用缩放
