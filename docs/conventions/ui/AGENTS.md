# UI 规范索引

做任何界面前先读本文件，再**只读命中的那一个**类型文件。规则为强制（MUST / MUST NOT），附一行 rationale，文末有 checklist。

- 选组件库、定设计 token、配色字体图标 → `design-system.md`
- 页面布局、响应式、司机 H5 适配 → `layout-responsive.md`
- 表单、校验反馈、状态标签、空 / 错状态 → `form-feedback.md`
- 可访问性、键盘、对比度、触控区 → `accessibility.md`
- 避免「AI 味」的禁止清单与正向目标 → `anti-ai-patterns.md`

术语以仓库根 `GLOSSARY.md` 为准。
